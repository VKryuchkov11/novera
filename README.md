# Novera — прогулки по Воронежу

PWA-приложение Novera для самостоятельных прогулок и открытий в Воронеже.

## Что добавлено в этой версии
- база из **28 точек интереса**: малоизвестные исторические дома, усадьбы, литературные адреса, парки и городские места;
- генератор прогулок по времени и тематике;
- режим «Удиви меня» и фильтр ещё не открытых мест;
- предварительный подбор последовательности точек эвристикой ближайшего соседа;
- пешеходная маршрутизация через Valhalla по данным OpenStreetMap: геометрия пути, расчёт расстояния и времени в пути, текстовые инструкции поворотов;
- генератор проверяет фактическую длину/длительность и сокращает список остановок, если прогулка не укладывается в выбранное время;
- сохранение открытых точек в localStorage;
- карточки с краткими описаниями и фактами, GPS-геозоны, прогресс и озвучивание;
- три прежних готовых маршрута, карта Leaflet/OSM, светлая/тёмная тема и PWA.

## Запуск
1. Распакуй архив.
2. Открой папку в VS Code.
3. Запусти через Live Server или другой локальный HTTP-сервер.
4. Для установки PWA и геолокации на телефоне размести проект на HTTPS-хостинге.

## Как работает генератор и маршрутизация
1. Фильтрует точки по выбранной теме и, если включено, исключает уже посещённые.
2. Эвристика ближайшего соседа предлагает начальный порядок максимум из пяти точек.
3. Координаты отправляются в Valhalla с профилем `pedestrian`.
4. Valhalla возвращает путь по пешеходной дорожной сети, длину, расчётное время и инструкции манёвров.
5. Если путь вместе с условными пятью минутами на каждую остановку превышает лимит пользователя, генератор убирает последнюю точку и пересчитывает маршрут.

Это алгоритмический подбор, а не нейросеть. Valhalla строит путь по данным OpenStreetMap; она не знает о временных перекрытиях, всех закрытых проходах, ремонтах, качестве тротуара или фактической безопасности конкретного места.

## Источники и точность данных
Координаты 21 малоизвестного исторического объекта взяты из опубликованной подборки «Малоизвестные места Воронежа», где указаны данные OpenStreetMap и Wikidata: https://geo-compas.ru/geo/maloizvestnye-mesta/voronezh
Список туристических объектов и парков сверялся с официальным туристско-информационным центром Воронежа: https://visit-voronezh.ru/guide/chto-posetit/
Справочные материалы также использовались для проверки городских маршрутов и общеизвестных объектов.

**Важно:** это исследовательская база для прототипа. Перед реальным использованием нужно перепроверить координаты, фактическое состояние зданий, возможность безопасного подхода и актуальные ограничения доступа. Для частных домов и усадеб маршрут означает только внешний осмотр с общедоступной улицы. Не заходи во дворы, на стройки, в руины или на закрытые территории.

## Технические ограничения
- Маршрут прокладывается по доступной в OpenStreetMap пешеходной сети. Данные OSM могут быть неполными или устаревшими; фактические проходы, переходы, лестницы, ремонты и безопасность нужно проверять на месте.
- Время Valhalla — расчётная оценка, а время на осмотр каждой точки условно принято равным пяти минутам. Реальная длительность зависит от темпа и остановок.
- Публичный сервер Valhalla — демонстрационный сервис с fair-use и ограничениями частоты запросов. Для массового/публичного запуска следует развернуть собственный сервер или выбрать коммерческий хостинг.
- Если сервис недоступен, приложение не рисует фиктивную прямую линию: предпросмотр показывает только точки и сообщает об ошибке. Запуск прогулки без рассчитанной геометрии заблокирован.
- Геозоны требуют разрешения на геолокацию; для GPS и Service Worker нужен HTTPS (кроме localhost).
- iOS может ограничивать GPS при сворачивании приложения или блокировке экрана.
- Тайлы OpenStreetMap и Leaflet CDN требуют интернет; офлайн-карта не реализована.
- Посещённые точки хранятся локально в браузере на устройстве и не синхронизируются между устройствами.

## Структура
- `index.html` — интерфейс
- `css/styles.css` — адаптивные стили
- `js/app.js` — интерфейс, генератор и GPS-логика
- `js/map.js` — карта и геолокация
- `js/routing.js` — запросы к Valhalla и декодирование полилинии маршрута
- `js/storage.js` — тема, оценки и коллекция открытий
- `data/routes.json` — три готовых маршрута
- `data/places.json` — база точек интереса
- `manifest.json` — PWA
- `service-worker.js` — кэширование файлов приложения

## Поставщик маршрутизации
- Valhalla API: https://valhalla.github.io/valhalla/api/route/api-reference/
- Публичный сервер и правила использования: https://valhalla.github.io/valhalla/start/introduction/
- Формат полилинии Valhalla использует точность 6 знаков: https://valhalla.github.io/valhalla/api/decoding/

В `js/routing.js` можно заменить `VALHALLA_ENDPOINT` на адрес собственного экземпляра Valhalla. Публичный endpoint не является гарантированным production API.
